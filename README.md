# rosana3.borzanti.com — versão alternativa clara

Mesma identidade do rosana2, com topo claro (creme e rosado) e rolagem natural nos atendimentos
(sem capítulos fixos). O vídeo do hero foi retirado a pedido.
Gerado de `D:\Sites\rosana-alt` com:

    cd D:\Sites\rosana-alt\app
    STATIC_EXPORT=1 VITE_VARIANT=light VITE_SITE_URL=https://rosana3.borzanti.com bunx --bun vite build

e cópia de `app/dist/client` para cá (sem `presets`). Versão de avaliação: noindex.
